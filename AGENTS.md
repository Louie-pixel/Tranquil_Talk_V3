# Tranquil Talk

- Keep the interface modern, calm, responsive and accessible.
- Do not use emojis in application screens, generated copy, documentation or future builds. Use restrained typography, CSS or accessible SVG icons when an icon is useful.
- Build on the existing C++/Drogon, MongoDB and shared browser/Qt architecture.
- Keep professional credentials, review notes and account information out of public profile responses.
- Verification must be an explicit administrator review. Never grant expert/admin privileges from public signup or owner-supplied profile fields.
- Use charcoal backgrounds and muted red accents. Main navigation must show separate pages rather than every feature in one scrolling page.
